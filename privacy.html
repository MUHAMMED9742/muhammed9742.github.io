Privacy Policy

FEEDBACK SYSTEM is a personal tool used only by its owner to analyse the owner's own YouTube channels.

What data is accessed

With read-only permissions, the tool reads channel and video statistics of the owner's own channels from the YouTube Data API and YouTube Analytics / Reporting APIs.

How data is stored and used

Data is stored only on the owner's own computer and is used only to produce reports for the owner. It is not sold, shared or transferred to any third party.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
